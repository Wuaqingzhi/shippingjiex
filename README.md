视频解析 v1.0.0 应用介绍
 
简介
 
视频解析是一款基于开源yt-dlp内核二次开发的安卓视频解析下载工具，支持粘贴网页链接，快速提取视频、音频资源并本地保存，无需登录账号，打开即可直接使用。
 
核心功能
 
1. 🔗 链接解析：粘贴视频网页地址，自动解析媒体资源，支持批量任务下载
2. 🎞️ 格式选择：可自选视频清晰度、音频码率，单独提取音频
3. 📥 下载管理：内置下载列表，支持暂停、继续、删除任务，查看下载进度
4. 📂 文件管理：下载完成的音视频直接保存到手机本地，方便查看
5. ⚙️ 精简设置：去除无关社区链接，界面干净简洁，无多余广告
